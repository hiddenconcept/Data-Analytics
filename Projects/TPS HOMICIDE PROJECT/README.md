About This Dataset

I started this project after discovering that, here in Canada, we have access to a large amount of free public data through Canadian government agencies. While working through the Coursera Power BI program, I learned how important it is to understand the structure, quality, and credibility of the data being used. Reliable data is essential for creating meaningful reports, identifying trends, and finding accurate insights.

This project focuses on homicide data published by the Toronto Police Service. The goal is to explore the dataset through data analytics and visualization techniques, while also practicing data cleaning, transformation, and reporting skills using tools such as Power BI.

The dataset includes information related to homicide investigations in Toronto and can be used to analyze trends over time, locations, demographics, case statuses, and other patterns that may provide useful insights.

Purpose of This Project
Practice real-world data analysis skills
Improve Power BI reporting and dashboard creation
Work with publicly available government datasets
Explore trends and patterns within Toronto homicide data
Demonstrate data cleaning and transformation workflows
Project Status

This project is currently a work in progress. Additional analysis, visualizations, and documentation will continue to be added over time.
